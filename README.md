# Pawn Forever

An add-on for [Pawn](https://www.curseforge.com/wow/addons/pawn) on **WoW Forever**. It does three things:

1. **Reads the tooltip lines Pawn misses on Forever.** Pawn 2.14.1 scores these as 0:
   - `Restores +4 mana per 5 sec.` (914 Forever items)
   - `Equip: Increases healing done by magical spells and effects by up to 12.` (235 items)
   - Zone-bonus lines such as `... by up to 8. This effect is tripled in Forest and Grassland areas.` (the base value counts)

   Running Pawn's own patterns over 32,142 real Forever tooltips leaves 4,354 stat lines unread. With Pawn Forever installed, 3,147 remain, and they are procs, "Use:" effects and set names that Pawn doesn't score anyway.
2. **Fixes the hover lag.** On Forever, Pawn re-reads an item's whole tooltip every time it looks up a cached value, which makes hovering items stutter. Pawn Forever trusts an item once Pawn has returned the same result twice. This is temporary and comes out once Pawn fixes it upstream.
3. **Adds "Pawn Forever" weights for every spec** of all nine classes, plus Forever's extra builds (Battle Mage, Shockadin, Enhancement Tank). Below level 60 the leveling weights apply. At 60 the scales switch to endgame weights automatically.

## Languages
The new tooltip patterns are built from the game's own localized tooltip strings (`TOOLTIP_ITEM_STAT_*`, `ITEM_MOD_*`), so they work on every client language Pawn supports. Each pattern is only added if Pawn doesn't already read that line, so the fixes switch themselves off as Pawn catches up. `/pff patterns` lists the patterns your client uses. Only the English client has been tested in game.

## Install
Copy the `PawnForever` folder into `World of Warcraft\_forever_\Interface\AddOns\`. Pawn must also be installed. Then restart the game or log out to character select.

The first time each character logs in, Pawn Forever shows its own scale in place of every Pawn stock scale you had visible for your class. After that it never changes which scales are visible.

## Commands
- `/pff forever` uses the Pawn Forever scales for your class.
- `/pff stock` goes back to Pawn's stock scales.
- `/pff diag` lists the tooltip lines Pawn still can't read on your equipped and bag gear. The full list is saved to `PawnForeverDB.diag` on `/reload`.
- `/pff patterns` lists the extra tooltip patterns active on your client.

## The weights
`PawnForever/Weights.lua` is generated by `tools/generate_weights.lua`.

- **Most specs** start from the per-spec Forever weight tables shipped with [GearQuest Forever](https://www.curseforge.com/projects/1698950) by Henrik8210, which score per point of rating. Pawn reads Forever's crit, hit, dodge and parry as percentages, so the generator converts them using the ratings printed on real Forever tooltips: crit 14, hit 10, dodge 12 and parry 15 per 1%. Haste (10) and block (5) are estimates, because no Forever item in that data has them.
- **Leveling** values multiply stamina and health ×3, and armor, Intellect, Spirit, Mp5 and mana ×2. These are GearQuest's leveling multipliers. Level 60 uses the base values.
- **Balance and Restoration druid** are hand-tuned (Pawn units, crit/hit/haste per 1%):

  | | Spell dmg | Healing | Int | Spirit | Mp5 | Crit | Hit | Haste | Stamina |
  |---|---|---|---|---|---|---|---|---|---|
  | Balance, leveling | 1 (+0.55 Nature, +0.5 Arcane) | 0 | 0.55 | 0.3 | 0.9 | 8 | 10 | 4 | 0.15 |
  | Balance, 60 | same | 0 | 0.45 | 0.1 | 0.6 | 8 | 10 | 4 | 0.1 |
  | Resto, leveling | 0 | 1 | 0.6 | 0.6 | 2 | 4 | 0 | 3 | 0.1 |
  | Resto, 60 | 0 | 1 | 0.5 | 0.5 | 2.5 | 4 | 0 | 3 | 0.1 |

  Sources: the brokenmeta level-60 Balance sim (hit ≈ 9/%, crit ≈ 7.4/%, Int 0.48 vs spell power), theforeverera weights (Balance crit 9/% and hit 12/%; Resto Mp5 3, Spirit 0.6, Int 0.5), and GearQuest Forever. Leveling values lean harder on regen.

A damage-and-healing line counts as both SpellDamage and Healing, so healing scales value it fully and caster DPS scales value its damage part.

To change weights, edit `tools/generate_weights.lua` and run it from the repo root:

    luajit tools/generate_weights.lua "<AddOns>/GearQuestForever/_generated/ScoringWeights.generated.lua"

## Development
- `luajit tools/check_regexes.lua` runs Pawn's tooltip patterns plus Pawn Forever's over GearQuest Forever's 32k tooltip audit and lists the stat lines nobody reads. Add `--stock` to see Pawn alone. It needs Pawn and GearQuest Forever installed. The `ADDONS` environment variable points it at your AddOns folder.
- `tools/fixtures/globals_enUS.lua` holds the English game strings the patterns are built from, dumped from the Forever client.
- `tools/wowcmd.ps1 -Cmd "/reload" -Shot shot.png` types a slash command into the running WoW window and screenshots it (Windows).

## Releasing
1. Add a `## x.y.z (date)` section at the top of `CHANGELOG.md` and commit.
2. Tag and push: `git tag vx.y.z && git push origin vx.y.z`.

`.github/workflows/release.yml` then builds `PawnForever-vx.y.z.zip`, which contains the `PawnForever` folder with the version stamped into the .toc. It creates a GitHub release using that changelog section. It also uploads to CurseForge once the repo has the `CF_API_TOKEN` secret and the `CF_PROJECT_ID` and `CF_GAME_VERSION_IDS` variables. The workflow file explains where to find each one.

## Reported upstream
- Pawn's parsing gaps above and the hover lag (reported to Vger).
- Pawn's stock Forever Fire mage scale has `FireSpellDamage=95` (should be about 0.95), so any fire-damage item looks like a huge upgrade on that scale.
